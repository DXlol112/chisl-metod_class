# Мини-задание для закрепления

## Что надо было сделать

Напиши функцию `relative_error(approx, exact)`, которая возвращает $\delta x$, и проверь её на:

- $\pi$ и $3.14$;
- $(0.1 + 0.2)$ и $0.3$ — обрати внимание, насколько результат «не 0»;
- сумме миллиона $0.1$ против `math.fsum`.

Сравни $\Delta x$ и $\delta x$ для каждого случая и запиши вывод: где абсолютная погрешность мала, а относительная велика (и наоборот). Это упражнение научит тебя смотреть на ошибку с двух сторон — и не доверять числам, которые «выглядят точно».

## Решение

```python
import math

def relative_error(approx,exact):
    return abs(approx - exact) / abs(exact)

def absolute_error(approx, exact):
    return abs(approx - exact)


values = [0.1] * 1_000_000
ordinary_sum = 0.0
for value in values:
    ordinary_sum += value

test_num = [
    ("Pi vs 3.14", 3.14, math.pi),
    ("0,1 + 0,2 vs 0.3", 0.1 +0.2, 0.3),
    ("manual sum mil 0.1 vs math.fsum", ordinary_sum, math.fsum(values))
]

for name, approx, exact in test_num:
    relative = relative_error(approx, exact)
    absolute_x = absolute_error(approx, exact)
    
    print(
        f"---- {name} -----\n"
        f"Приближённое: {approx}\n"
        f"Точное:       {exact}\n"
        f"Абсолютная погрешность: {absolute_x}\n"
        f"Относительная: {relative}"
    )

```

Вывод:

### Вывод

- **$\pi$ и $3.14$** — абсолютная погрешность $0.00159$, относительная $0.051\%$. Cамые большие погрешности среди трёx.
- **$0.1 + 0.2$ и $0.3$** — абсолютная погрешность $5.55 \times 10^{-17}$, относительная $1.85 \times 10^{-16}$. Почти нулевые.
- **Сумма миллиона $0.1$** — при сложении в цикле ошибки накопились. Абсолютная погрешность около $1.33 \times 10^{-6}$, а относительная $1.33 \times 10^{-11}$, поскольку сама сумма равна $100000$.
